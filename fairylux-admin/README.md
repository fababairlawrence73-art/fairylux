# FairyLux admin and API

Follow the [repository setup guide](../README.md) for Windows prerequisites, MySQL, demo accounts, product photos and Firebase notifications.

After setup, run `composer run dev` from this directory. Open http://127.0.0.1:8000 and log in with `admin@fairylux.com / password`.

Checks: `php artisan test` and `npm.cmd run build`.
